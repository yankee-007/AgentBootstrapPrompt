## 固定版本与升级

`main` 是可变的发现入口；执行时先解析完整 SHA，重新读取该 SHA 的入口及全部依赖。需要复现某次版本时保存实际核验过的完整 SHA/永久链接，版本号文本不代替提交固定，也不把旧永久链接描述为新内容。

本地/离线包以其完整内容为准；能核验来源提交时记录，不能时写“未核验来源提交”。创建 ZIP 后逐文件比对源文件与归档内容。

已有目标项目独立持有规则，不自动下载升级。用户明确要求升级时先比较实际策略和最低语义缺项，再最小补充并更新来源记录；不覆盖用户规则，不扩大 Git 或远端授权。
