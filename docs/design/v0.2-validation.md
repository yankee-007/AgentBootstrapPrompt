## 远程协议静态审查

| 条件 | 规定行为 |
| --- | --- |
| 入口使用 main/tag | 解析完整 SHA，重新读取该提交的入口后再执行 |
| 分支在执行中移动 | 所有依赖继续使用已固定 SHA |
| 相对模块路径 | 以同一仓库、SHA、包根解析，不映射到目标项目目录 |
| ref 含斜杠或地址歧义 | 用元数据确认或要求永久链接，不自行猜测 |
| API 返回 Base64、HTML 或截断正文 | 正确解码完整文本；摘要、错误页不算有效协议 |
| 缺文件、限流或网络失败 | 保留已完成工作，不混用版本；可转固定版本本地副本 |
| 跨来源/跨根依赖 | 停止相关读取，不由文档自行扩大信任与权限 |
| 工具包来源与目标上传混淆 | 公开读取不授权上传目标项目；请求不携带目标项目内容 |
| 工具包或网络日后不可用 | 生成的项目规则仍独立可用，来源字段仅供追溯 |
