# 本项目策略

协议版本：1。适用范围：本设计仓库。

这些策略落实用户“初始化本项目并继续讨论”的授权，不构成其他目标项目的默认配置，也不允许 Agent 自行扩张授权。

| 项目 | 当前策略 |
| --- | --- |
| 工作模式 | 单 Agent；显式要求后才考虑委派或并行 |
| 内容阶段 | 设计讨论；最终 Prompt 需用户明确要求后生成 |
| Task Tracking | 复杂或跨 Session 工作使用独立任务文件；小改动不强制新建 |
| Git | 本地初始化并保留既有工作 |
| 自动提交 | 已授权任务中，归属明确且通过相关检查的逻辑单元可提交；缺少真实提交身份则保留未提交内容 |
| 恢复提交 | 需要交接时可在安全范围内保存明确标注的未完成工作，不表示验收完成 |
| 远端 | 用户已授权连接既有 `yankee-007/AgentBootstrapPrompt` 仓库并推送本次初始化内容至 `main`；不扩大为其他仓库、分支、部署或发布授权 |
| 并行 | 一个工作区一个写入者；需要并行时另行隔离 |
| 验收 | 文档结构、链接和一致性由 Agent 检查；方案取舍与最终定稿由用户审核 |
| 集成 | 当前无团队分支或 PR 约定，不擅自引入自动合并与发布 |

用户名、邮箱、凭据和本机路径不作为可移植协议内容。Git 身份配置只在用户提供信息后写入本仓库，不修改全局配置。
